Add a person:

node app.js add --fname="Omar" --lname="Ezzat" --age=25 --city="Cairo" --id=1
node app.js add --fname="Ahmed" --lname="Ali" --age=23 --city="Giza" --id=2

📖 Read a person:

node app.js read --id=1

📋 Display all persons:

node app.js list

🗑️ Delete a person:

node app.js delete --id=1
